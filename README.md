# JAViewer
质感设计 更优雅的驾车体验

## 项目背景

本项目是基于原项目 **JAViewer**（作者：hitokunys）的二次开发（fork）。

- 原项目源码: https://github.com/hitokunys/JAViewer
- 本仓库地址: https://github.com/SplashCodes/JAViewer

在保留原有浏览、搜索、播放等核心功能的基础上，进行了修复与增强：

- 磁力搜索三 Tab（BtSearch / 无极磁链 / btsow）
- 分类页支持保留日文原文标签
- 侧边栏源码入口、数据源域名编辑
- 版本兼容性优化（全 ABI、存储权限适配）
